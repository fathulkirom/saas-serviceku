## 🔄 QC Workflow

```
Technician completes repair → Service status: selesai
  → QC technician runs through 22 checks
  → ALL 22 PASS → QC passed → Status: siap_diambil
  → ANY FAIL → QC failed → Status: kembali ke dikerjakan → Technician fixes → Repeat QC
```

---

## ⚠️ QC Failure Handling

- Specific failed items recorded with notes
- Technician notified via Notification Center
- Internal note added explaining failure
- QC history preserved for audit

# Insurance Management

> Asset insurance policy tracking: coverage, premium, claims, renewal.

---

## 🔒 Insurance Lifecycle

```
Policy Purchased → Insurance Active
  → Premium Due → Payment → Active
  → Expiring (30 days) → Alert → Renewal
  → Claim Filed → Payout/Repair
  → Expired → Flag
```

---

## 📊 Coverage Types

| Type | Description |
|------|-------------|
| All Risk | Full coverage |
| Fire | Fire damage only |
| Theft | Theft/loss only |
| Third Party | Liability |
| Comprehensive | All risk + third party |

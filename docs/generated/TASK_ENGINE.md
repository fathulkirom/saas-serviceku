# Task Engine

> Full task management with Kanban, priorities, dependencies, time tracking, and labels.

---

## ✅ Task Status (Kanban Columns)

| Column | Description |
|--------|-------------|
| Backlog | Ideas, not yet prioritized |
| To Do | Ready to start |
| In Progress | Currently working |
| Review | Under review |
| Testing | QA/Verification |
| Done | Completed |
| Blocked | Cannot proceed |

---

## 📋 Task Features

| Feature | Description |
|---------|-------------|
| Sub Tasks | Nested task breakdown |
| Checklist | Per-task checklist items |
| Recurring Tasks | Repeat daily/weekly/monthly |
| Templates | Reusable task templates |
| Priority | Critical / High / Medium / Low |
| Dependencies | Blocked by / Blocks |
| Estimates | Estimated hours |
| Actual Time | Tracked hours |
| Labels | Color-coded tags |
| Comments | Thread discussion |
| Attachments | Files per task |
| Watchers | Notification subscribers |

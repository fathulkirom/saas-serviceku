# Service QC Guide — Sprint 36A

> Quality Control mandatory checklist — 16 items, ALL must pass before service is ready for pickup.

---

## 🔍 QC Checklist (16 Items — ALL Mandatory)

| # | Check | Description |
|---|-------|-------------|
| 1 | All Functions | Semua fungsi utama berjalan normal |
| 2 | Charging | Charging berfungsi normal |
| 3 | Camera | Kamera depan & belakang OK |
| 4 | Mic & Speaker | Mic & Speaker OK |
| 5 | WiFi | WiFi terhubung normal |
| 6 | Bluetooth | Bluetooth pairing OK |
| 7 | LCD | LCD tidak ada dead pixel / garis |
| 8 | Touch | Touchscreen responsif seluruh area |
| 9 | Fingerprint | Fingerprint / Face ID berfungsi |
| 10 | Keyboard | Keyboard semua tombol berfungsi |
| 11 | Trackpad | Trackpad responsif |
| 12 | Stress Test | Stress test 30 menit lulus |
| 13 | Burn Test | Burn test 1 jam lulus |
| 14 | Battery Test | Baterai bertahan minimal 2 jam |
| 15 | Physical | Tidak ada kerusakan fisik baru |
| 16 | Cleaning | Unit bersih dari debu/sisa perbaikan |

---

## 🔄 QC Workflow

```
Technician marks service "selesai"
  → QC technician opens QC checklist
  → Runs through ALL 16 checks
  → ALL PASS → Mark QC passed → Status: siap_diambil
  → ANY FAIL → Mark QC failed → Status: kembali ke dikerjakan
```

---

## ⚠️ QC Failure Handling

- QC fail → Status kembali ke `dikerjakan`
- Technician receives notification
- Internal note added with specific failure items
- After rework → Technician marks `selesai` again → QC repeats

---

## 📸 QC Photo Requirements

- Photo of completed repair (category: `completed`) — required
- Photo during QC testing (category: `qc`) — required
- Minimum: 2 photos

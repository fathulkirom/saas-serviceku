# Customer Chat

> Real-time chat: Customer ↔ CS, Customer ↔ Technician, with file/photo sharing.

---

## 💬 Chat Features

| Feature | Description |
|---------|-------------|
| Customer ↔ CS | General support chat |
| Customer ↔ Technician | Job-specific chat |
| File Attachment | Photos, PDFs |
| Image Upload | Device photos |
| Voice Note | Voice messages |
| Typing Indicator | Real-time typing status |
| Read Status | Message read receipts |
| Chat History | Searchable history |

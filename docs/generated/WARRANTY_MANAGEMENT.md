# Warranty Management

> Asset warranty tracking: standard, extended, vendor warranty with claim management.

---

## 🛡️ Warranty Types

| Type | Description | Duration |
|------|-------------|----------|
| Standard | Manufacturer warranty | 1–3 years |
| Extended | Additional purchased warranty | +1–2 years |
| Vendor | Third-party service warranty | Contract-based |

---

## 📋 Warranty Lifecycle

```
Asset Purchased → Warranty Active
  → Warranty Expiring (30 days before) → Alert
  → Warranty Expired → Flag as Expired
  → Claim Filed → Claim Status Tracked
  → Replacement/Repair → Warranty Updated
```

---

## 🔍 Claim Management

| Claim Status | Description |
|-------------|-------------|
| Filed | Claim submitted |
| In Review | Vendor reviewing |
| Approved | Claim approved |
| Rejected | Claim rejected |
| Completed | Repair/replacement done |

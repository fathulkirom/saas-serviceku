# Warehouse Workspace

> Complete WMS workspace — 16 tabs, 4 sidebar widgets.

---

## Tab List

| Tab | Content |
|------|---------|
| **Overview** | KPI — utilization %, receiving, picking/packing queues, shipments, cycle counts due, variances |
| **Warehouse** | Multi-warehouse — code, name, branch, zone, bin, capacity, utilization, SKU count, manager |
| **Locations** | Zone → Rack → Shelf → Bin hierarchy management |
| **Putaway** | Receiving → auto/manual putaway with location suggestion + zone strategy |
| **Picking** | Wave/batch/zone/cluster/single picking with priority |
| **Packing** | Packing station — package type, weight, volume, label, carrier, seal |
| **Shipping** | Shipments — courier, fleet, 3PL, tracking, manifest, route, POD |
| **Receiving** | ASN → inspection → partial/full/over/under receive → quality hold |
| **Transfers** | Warehouse/branch/bin/zone transfer with transit tracking |
| **Cycle Count** | ABC/scheduled/blind/physical counts with reconciliation |
| **Stock Movement** | All inventory movement history |
| **Cross Dock** | Cross-docking operations |
| **Timeline** | Full warehouse activity timeline |
| **Activity Log** | Complete audit trail |
| **Documents** | Receiving reports, packing lists, manifests, POD |
| **History** | Complete warehouse operations history |

---

## Picking Strategies

| Strategy | Description |
|----------|-------------|
| Wave | Group orders by time window |
| Batch | Group same-SKU across orders |
| Zone | Divide warehouse into zones |
| Cluster | Pick multiple orders simultaneously |
| Single | One order at a time |

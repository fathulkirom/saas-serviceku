# AI Workspace

> 16-tab AI Intelligence Workspace — the command center for all AI capabilities.

---

## Tab List

| Tab | Content |
|------|---------|
| **Overview** | Business health, risks, recommendations, insights, predictions, enterprise chat |
| **Enterprise Chat** | Context-aware AI: module context, role context, record context, memory |
| **Workflow Assistant** | Next status, assignee, escalation, priority, risk detection |
| **Recommendations** | Pending/accepted/implemented AI recommendations |
| **Insights** | Daily/weekly summaries, trend analysis, anomaly detection |
| **Predictions** | Sales, revenue, demand, churn, cash flow forecasts with confidence |
| **Decision Center** | Decision history with 👍/👎 feedback |
| **Smart Automations** | AI-optimized automations, conflict detection |
| **Smart Reports** | AI-explained reports, executive summaries, action items |
| **AI Tasks** | AI-generated action items |
| **Notifications** | Briefings, alerts, summaries |
| **Knowledge** | Semantic search, document/SOP/FAQ recommendations |
| **Learning** | Feedback, corrections, prompt optimization stats |
| **Conversations** | Full conversation history |
| **Prompt Library** | Saved prompts: personal, team, department, global |
| **Audit Trail** | Complete AI interaction log |

## AI Context Awareness

| Context | Example |
|---------|---------|
| Module | "I'm in Service module" → service-aware responses |
| Role | Cashier sees POS AI, Manager sees all |
| Tenant | Tenant-specific data only |
| Business Type | Retail vs Manufacturing AI scope |
| Current Record | "Analyze this service" → current record context |
| Permission | Finance data masked for non-finance roles |

# BOM Engine (Bill of Materials)

> Multi-level BOM with versioning, alternative BOM, cost rollup.

---

## 📦 BOM Features

| Feature | Description |
|---------|-------------|
| Multi-Level | Parent → Child → Sub-child hierarchy |
| Alternative BOM | Multiple BOMs per product |
| Versioning | Version tracking with effective dates |
| Active/Inactive | Activate/deactivate versions |
| Sub Assembly | Nested sub-assemblies |
| Phantom BOM | Temporary sub-assembly |
| Scrap % | Expected scrap per component |
| Yield % | Expected yield |
| Cost Rollup | Roll up component costs |
| Attachments | Drawings, specs |
| Approval | BOM approval workflow |

---

## 🤖 AI Capabilities

| Capability | Description | Input |
|------------|-------------|-------|
| Satisfaction Prediction | Predict post-service satisfaction | Service history, rating trend, complaint count |
| Repeat Customer Prediction | Likelihood of return within 30 days | Repair frequency, spending, engagement |
| Review Sentiment Analysis | Analyze review text for sentiment | Review text + rating |
| Complaint Pattern Analysis | Detect systematic issues | Complaint history across customers |
| Promo Recommendation | Best promo for this customer | Segment, device types, spending |
| Loyalty Recommendation | Suggested loyalty tier | Points, service count, member since |
| Follow-up Recommendation | Best follow-up action | Last service type, days since |

# Audit Engine

> Internal and external audit management with finding tracking, evidence collection, and CAPA integration.

---

## 🔍 Audit Types

| Type | Description |
|------|-------------|
| Internal Audit | Scheduled audits by internal audit team |
| External Audit | Third-party auditor engagements |
| Surveillance Audit | Ongoing compliance surveillance |
| Special Audit | Ad-hoc investigation audits |
| Follow-up Audit | Verification of previous findings closure |

---

## 📋 Audit Lifecycle

```
Plan → Schedule → Execute → Findings → CAPA → Verify → Close
```

### Key Features
- Audit program management with checklists
- Evidence collection and document linking
- Finding classification (Critical, Major, Minor, Observation)
- Automatic CAPA creation from findings
- Auditor assignment and scheduling
- Audit report generation

---

## 📊 Audit KPIs

- Audits completed vs planned
- Findings by severity and module
- CAPA closure rate
- Average time to close findings
- Recurrence rate (repeat findings)

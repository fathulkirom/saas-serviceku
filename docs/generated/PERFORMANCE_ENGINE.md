# Performance Engine

> KPI-based performance evaluation with grade, recommendation, and promotion/demotion tracking.

---

## 📈 KPI Components

| Component | Weight | Description |
|-----------|--------|-------------|
| Target Achievement | 40% | Achievement vs set targets |
| Quality | 25% | Work quality score |
| Attendance | 15% | Attendance rate |
| Discipline | 10% | Punctuality, compliance |
| Teamwork | 10% | Collaboration score |

---

## 🏆 Grade System

| Grade | Score Range | Recommendation |
|-------|-------------|----------------|
| A | 90–100 | Promotion / Bonus |
| B | 75–89 | Good — increment |
| C | 60–74 | Average — coaching |
| D | 45–59 | Below — warning |
| E | 0–44 | Poor — PIP |

---

## 📊 Review Cycles

| Cycle | Period | Frequency |
|-------|--------|-----------|
| Probation | 3 months | End of probation |
| Quarterly | 3 months | Quarterly review |
| Semi-Annual | 6 months | Mid-year review |
| Annual | 12 months | Yearly review |

---

## 🔗 Integration

| Integration | Description |
|-------------|-------------|
| Payroll | Grade → bonus/increment |
| Training | Low score → training recommendation |
| Automation | Review due → task reminder |

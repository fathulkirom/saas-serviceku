# Document Workspace

> Complete DMS workspace — 16 tabs, 4 sidebar widgets.

---

## Tab List

| Tab | Content |
|------|---------|
| **Overview** | KPI — total docs, pending approvals, KB articles, uploads, expired, approvals queue, recent docs, top knowledge, team activity |
| **Preview** | In-browser PDF/image/doc preview |
| **Versions** | Major/minor version list, compare, restore, diff |
| **Approval** | Approval chain status — pending/approved/rejected/escalated |
| **History** | Complete change history |
| **Metadata** | All metadata fields |
| **Sharing** | Share link generation, expiry, access tracking |
| **Permissions** | Role-based + user-based permissions |
| **Comments** | Threaded comments with @mentions |
| **Attachments** | Related files and documents |
| **OCR** | OCR text extraction results |
| **Timeline** | Document activity timeline |
| **Activity Log** | Full activity feed |
| **Audit Trail** | Complete audit log |
| **Related Docs** | Linked/related documents |

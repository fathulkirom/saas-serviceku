# Tenant Analytics

> Growth, MRR, ARR, churn, active users, transactions, AI usage, feature adoption, health score.

---

## 📊 Analytics Metrics

| Metric | Description |
|--------|-------------|
| Growth | New tenants per month |
| MRR | Monthly Recurring Revenue |
| ARR | Annual Recurring Revenue |
| Churn | Churn rate + reasons |
| Active Users | DAU/MAU per tenant |
| Transactions | Total transactions |
| AI Usage | Token consumption |
| API Usage | API call volume |
| Storage Usage | GB per tenant |
| Module Usage | Which modules are used |
| Feature Adoption | % of features used |
| Health Score | Composite tenant health |

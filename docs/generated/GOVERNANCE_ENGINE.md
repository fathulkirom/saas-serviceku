# Governance Engine

> Board-level governance dashboard with KPIs, scorecards, and executive reporting.

---

## 🏛️ Governance Framework

```
Board/Owner → Governance Scorecard → Risk Management → Compliance → Internal Control
```

---

## 📊 Governance Scorecard

| KPI | Weight | Source |
|-----|--------|--------|
| Risk Management Score | 33% | Risk Engine |
| Compliance Score | 33% | Compliance Engine |
| Internal Control Score | 33% | Control Engine |
| **Governance Score** | **100%** | Weighted average |

- Real-time governance score with trend indicator
- Critical risk count with drill-down
- Open findings with aging analysis
- CAPA effectiveness trend
- Incident frequency and severity trends
- Compliance gap summary by framework
- Control failure rate by module

# Internal Control Engine

> COSO-based internal control framework with control testing, effectiveness ratings, and automated remediation.

---

## 🔒 Control Types

| Type | Description |
|------|-------------|
| Preventive | Stop errors before they occur (e.g., authorization, segregation of duties) |
| Detective | Identify errors after occurrence (e.g., reconciliations, audits) |
| Corrective | Fix errors after detection (e.g., backups, corrections) |
| Manual | Human-performed controls |
| Automated | System-enforced controls |

---

## 📋 Control Categories

| Category | Examples |
|----------|----------|
| Access Control | User permissions, role-based access |
| Authorization | Approval workflows, spending limits |
| Reconciliation | Bank rec, inventory counts, AR/AP aging |
| Segregation of Duties | Maker-checker, four eyes principle |
| Physical | Locks, cameras, access cards |
| IT General Controls | Change management, backup, DR |

---

## 🧪 Control Testing

- Scheduled testing per control frequency (Daily, Weekly, Monthly, Quarterly, Annual)
- Test results: Effective ✅, Weak ⚠️, Failed ❌, Under Review 🔍
- Automatic finding creation for failed controls
- Control effectiveness trending over time
- Remediation tracking with CAPA integration

---

## 📊 Effectiveness Dashboard

- Control effectiveness by module
- Failed controls requiring immediate attention
- Testing schedule compliance
- Control coverage gap analysis

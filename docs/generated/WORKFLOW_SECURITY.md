# Workflow Security

> Approval signature, immutable history, permission validation, dual control, four eyes, separation of duties.

---

## 🔒 Security Principles

| Principle | Description |
|-----------|-------------|
| Dual Control | Two-person approval for critical actions |
| Four Eyes | Maker + Checker |
| Separation of Duties | Requester ≠ Approver |
| Immutable History | Cannot modify approved records |
| Audit Trail | Every action logged |
| Permission Validation | Respect `can()` for all workflow actions |

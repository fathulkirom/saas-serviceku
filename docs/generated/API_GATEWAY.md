# API Gateway

> REST API with versioning, OpenAPI/Swagger, rate limiting, quotas.

---

## 🌐 API Features

| Feature | Description |
|---------|-------------|
| REST API | Standard REST endpoints |
| Versioning | `/v1/`, `/v2/` URI-based |
| GraphQL Ready | Single endpoint for flexible queries |
| OpenAPI Spec | Auto-generated OpenAPI 3.0 |
| Swagger Export | Swagger UI for developer portal |
| API Discovery | Auto-documented endpoints |
| API Groups | Group by module |
| Rate Limit | Per-key, per-endpoint limits |
| Throttling | Gradual backoff |
| API Quotas | Monthly/daily quota |
| Analytics | Usage tracking per endpoint/key |
| Deprecation | Sunset headers + migration docs |

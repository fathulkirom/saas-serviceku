# Workflow Designer

> Visual workflow builder — drag & drop ready, steps, decisions, parallel, merge, loop, timer.

---

## 🎨 Designer Elements

| Element | Description |
|---------|-------------|
| Step | Single action/task |
| Decision | Conditional branch (if/else) |
| Parallel | Multiple simultaneous paths |
| Merge | Combine parallel paths |
| Loop | Repeat until condition |
| Timer | Wait/delay step |
| Approval | Approval step with configurable type |
| Notification | Send message via Notification Hub |
| Automation | Trigger Automation Engine action |
| API Call | Call external API via Integration Hub |
| AI Decision | AI-powered decision step |

---

## 📐 Approval Types

| Type | Description |
|------|-------------|
| Single | One approver |
| Sequential | Chain of approvers |
| Parallel | Multiple simultaneous approvers |
| Majority | >50% approve |
| Consensus | 100% must approve |
| Multi-Level | Hierarchy-based levels |
| Conditional | Based on business rules |
| Auto Approve | AI/rule-based automatic approval |
| Auto Reject | AI/rule-based automatic rejection |

# Work Center Engine

> Machine, production line, work cell management with capacity and OEE.

---

## ⚙️ Work Center Types

| Type | Description |
|------|-------------|
| Machine | Single machine |
| Production Line | Multiple machines in sequence |
| Work Cell | Group of machines/operators |

---

## 📊 OEE (Overall Equipment Effectiveness)

| Component | Formula |
|-----------|---------|
| Availability | Actual Run Time / Planned Production Time |
| Performance | (Ideal Cycle Time × Total Units) / Actual Run Time |
| Quality | Good Units / Total Units |
| **OEE** | Availability × Performance × Quality |

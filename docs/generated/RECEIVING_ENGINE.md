## 📨 Receiving Flow

```
ASN Received (from Purchasing)
  → Physical Goods Arrive
  → Inspection (damage check)
  → Receive: Partial / Full / Over / Under
  → Damage Report (if any)
  → Quality Hold (if failed inspection)
  → Receiving Complete → Create Putaway Task
```

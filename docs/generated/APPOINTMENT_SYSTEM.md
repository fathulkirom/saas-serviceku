# Appointment System

> Customer appointment booking with branch, technician, time slot selection.

---

## 📅 Appointment Flow

```
Customer selects: Branch → Service Type → Date → Time Slot → Technician (optional)
  → System checks availability
  → Confirmation sent (WA + Email)
  → Reminder (24h before)
  → Customer arrives → Service created
  → No show? → Follow-up automation
```

---

## 🔧 Features

| Feature | Description |
|---------|-------------|
| Branch Selection | Choose preferred branch |
| Technician Preference | Select specific technician |
| Time Slot | 1-hour slots |
| Availability Check | Real-time slot check |
| Reschedule | Change date/time |
| Cancel | Cancel with reason |
| Reminder | Auto WA reminder |
| Calendar Ready | Integration point for Calendar Engine |

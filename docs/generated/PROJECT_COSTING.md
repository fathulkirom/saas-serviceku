# Project Costing

> Budget planning, actual cost tracking, variance analysis, Finance integration.

---

## 💰 Cost Categories

| Category | Description |
|----------|-------------|
| Labor Cost | Employee/technician hours × rate |
| Material Cost | Inventory items used |
| Asset Cost | Equipment/vehicle/tool usage |
| Vehicle Cost | Fuel, maintenance |
| External Cost | Vendor, subcontractor |
| Overhead | Indirect costs |

---

## 📊 Cost Tracking

```
Budget Planned
  → Labor Cost (Timesheet × Rate)
  → Material Cost (Inventory usage)
  → External Cost (Vendor invoices)
  → Actual Cost = Sum
  → Variance = Budget - Actual
  → Forecast = Based on trends
```

---

## 🔗 Finance Integration

- Project Cost → Finance Journal
- Client Invoice → AR
- Vendor Payment → AP

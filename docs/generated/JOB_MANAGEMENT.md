# Job Management

> Technician job assignment, tracking, completion, and verification.

---

## 🔧 Job Types

| Type | Description |
|------|-------------|
| Internal | Internal maintenance/repair |
| External | Customer site visit |
| Emergency | Urgent breakdown |
| Scheduled | Planned service |

---

## 📋 Job Lifecycle

```
Job Created → Assigned
  → En Route (GPS)
  → In Progress
  → Completed
  → Verified (Supervisor)
  → Closed
```

| Integration | Description |

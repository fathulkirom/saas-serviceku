# AI Security

> Role-based, permission-based, PII-protected AI with full audit trail.

---

## 🔐 Security Layers

| Layer | Description |
|-------|-------------|
| Role-Based AI | Different AI per role |
| Permission-Based | Respect `can()` throughout |
| Department Restriction | Department-scoped AI data |
| Sensitive Data Masking | Auto-mask PII in responses |
| Finance Restriction | Finance data for finance roles only |
| HR Restriction | HR data for HR roles only |
| Audit Trail | Every query + response logged |
| Conversation Log | Full conversation history |
| Prompt Log | All prompts tracked |
| Token Usage | AI consumption monitored |

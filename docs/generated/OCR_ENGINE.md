# OCR Engine

> PDF/image OCR with full-text search, metadata extraction.

---

## 🔍 OCR Features

| Feature | Description |
|---------|-------------|
| PDF OCR | Extract text from PDF |
| Image OCR | Extract text from images (PNG, JPG) |
| Full Text Search | Search extracted text |
| Metadata Extraction | Auto-extract metadata |
| Search Highlight | Highlight search results |
| Queue Processing | Background OCR processing |

---

## 🔗 OCR Workflow

```
Document Uploaded
  → OCR Queue (background)
  → Extract Text
  → Index for Full-Text Search
  → Metadata Auto-Extraction
  → OCR Completed → Notification
```

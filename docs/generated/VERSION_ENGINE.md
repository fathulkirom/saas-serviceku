# Version Engine

> Major/minor versioning with compare, restore, diff, lock.

---

## 🔄 Version Types

| Type | When |
|------|------|
| Major (1.0, 2.0) | Significant changes, new approval |
| Minor (1.1, 1.2) | Small updates, auto-save |

---

## 📋 Version Features

| Feature | Description |
|---------|-------------|
| Compare | Side-by-side version comparison |
| Diff | Highlight changes between versions |
| Restore | Roll back to previous version |
| Rollback | Undo current version |
| Lock Editing | Prevent concurrent edits |
| Branch | Create branch for parallel editing |

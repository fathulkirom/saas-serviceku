# API Security

> HMAC, JWT, OAuth, encryption, secret vault, key rotation, rate limiting, IP restriction.

---

## 🔒 Security Layers

| Layer | Description |
|-------|-------------|
| API Signature | Request signing with HMAC |
| JWT | Stateless token authentication |
| OAuth2 | Industry-standard authorization |
| Encryption | AES-256 for credentials |
| Secret Vault | Encrypted credential store |
| Key Rotation | Auto-rotate secrets |
| Request Validation | Input validation + sanitization |
| Rate Limiting | Per-key, per-endpoint |
| IP Restriction | Whitelist IP ranges |
| Audit Trail | Every API action logged |
| Security Events | Real-time security alerts |

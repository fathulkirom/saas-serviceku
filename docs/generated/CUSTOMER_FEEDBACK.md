# Customer Feedback — Sprint 36C

> Star rating, review, and AI sentiment analysis for service quality measurement.

---

## ⭐ Rating Categories (5 dimensions)

| Category | Weight | Description |
|----------|--------|-------------|
| Pelayanan CS | 25% | CS friendliness, clarity, responsiveness |
| Keahlian Teknisi | 30% | Repair quality, professionalism |
| Kecepatan Perbaikan | 20% | Service turnaround time |
| Kesesuaian Harga | 15% | Price fairness |
| Komunikasi | 10% | Update frequency, clarity |

## 🤖 AI Sentiment Analysis

AI analyzes review text for:
- Sentiment (positive/neutral/negative)
- Key topics mentioned
- Urgency (needs follow-up?)
- Pattern detection (recurring issues across customers)

---

## 📈 Feedback Flow

```
Service completed → 7 days after → Survey sent via WhatsApp
  → Customer rates 5 categories + writes review
  → AI analyzes sentiment
  → Low rating (<3) → CS flagged for follow-up
  → High rating (4-5) → Thank you message + promo offer
```

# Booking Service — Sprint 36C

> Online service booking for HP & Laptop repair.

---

## 📅 Booking Flow

```
Customer opens Customer Portal → Appointments tab
  → Select service type (screen repair, battery, water damage, etc.)
  → Select branch
  → Select date
  → Select time slot (09:00–17:00, hourly)
  → Describe problem
  → Upload photos (optional)
  → Submit booking
  → Receive booking number + confirmation
```

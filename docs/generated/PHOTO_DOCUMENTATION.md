# Photo Documentation — Sprint 36B

> Structured photo documentation for the complete repair lifecycle.

---

## 📸 Photo Categories

| Category | Required | Description |
|----------|----------|-------------|
| Before Repair | ✅ | Device condition at intake |
| During Repair | — | Work in progress |
| After Repair | ✅ | Completed repair result |
| Board Repair | — | Micro-soldering/board-level work |
| Component Replacement | — | Old vs new part comparison |
| QC | ✅ | Quality check evidence |
| Warranty Claim | — | Evidence for warranty claims |

---

## 🖼️ Photo Features

- **Multi Upload**: Select multiple photos at once
- **Drag Upload**: Drag & drop photos directly
- **Preview**: Full-screen photo viewer
- **Zoom**: Pinch/scroll to zoom
- **Annotation Ready**: Framework for drawing on photos
- **Compression**: Client-side compression (max 2MB per photo)

---

## 📋 Photo Requirements per Phase

| Phase | Min Photos | Purpose |
|-------|-----------|---------|
| Intake | 1 per issue | Document pre-existing condition |
| Disassembly | As needed | Document internal condition |
| Repair | As needed | Document repair process |
| Completed | 2 minimum | Overall result + detail |
| QC | 2 minimum | QC checks evidence |
| Handover | 1 | Proof of handover |

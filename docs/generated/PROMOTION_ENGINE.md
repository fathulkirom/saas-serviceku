# Promotion Engine

> 7 promotion types with auto-apply, channel targeting, and scheduling.

---

## 🎫 Promotion Types

| Type | Description |
|------|-------------|
| Percentage Discount | % off total or per item |
| Nominal Discount | Fixed Rp off |
| Buy X Get Y | Free item with purchase |
| Bundle | Bundle price for set |
| Happy Hour | Time-based discount |
| Flash Sale | Limited-time sale |
| Coupon/Voucher | Code-based discount |
| Membership Price | Special price for members |
| Tier Price | Quantity-based pricing |

---

## ⚙️ Auto-Apply Rules

- Match by product, category, customer tier
- Stackable or exclusive
- Channel-specific (POS only, website only, etc.)
- Branch-specific
- Minimum purchase threshold
- Maximum discount cap

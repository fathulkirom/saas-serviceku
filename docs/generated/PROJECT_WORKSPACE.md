# Project Workspace

> Complete project lifecycle workspace — 14 tabs, 4 sidebar widgets.

---

## Tab List

| Tab | Key | Content |
|-----|-----|---------|
| **Overview** | overview | KPI dashboard — active projects, budget, tasks due/overdue, progress bars, budget vs actual |
| **Planning** | planning | Objective, scope, deliverables, methodology, constraints |
| **Tasks** | tasks | Task list — backlog, todo, in progress, review, testing, done |
| **Kanban** | kanban | Drag & drop board with WIP limits and swimlanes |
| **Gantt** | gantt | Timeline chart — dependencies, critical path, milestones, baselines |
| **Timeline** | timeline | Activity timeline |
| **Milestones** | milestones | Milestone tracking — deadline, progress, deliverables |
| **Resources** | resources | Employee, equipment, vehicle, tool allocation + utilization |
| **Files** | files | Documents, drawings, contracts, version history |
| **Budget** | budget | Budget vs actual with variance analysis |
| **Cost** | cost | Cost breakdown by category |
| **Risks** | risks | Risk register — probability × impact, mitigation |
| **Issues** | issues | Issue log — bug, blocker, escalation |
| **Activity Log** | activity | Full audit trail |

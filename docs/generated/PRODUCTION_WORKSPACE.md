# Production Workspace

> Complete manufacturing workspace — 15 tabs, 4 sidebar widgets.

---

## Tab List

| Tab | Content |
|------|---------|
| **Overview** | Active orders, efficiency %, OEE, shortages, QC fails, machine status, scrap trend |
| **Production Order** | Orders list — draft → planned → in progress → completed |
| **BOM** | Bill of Materials — multi-level, versioned, cost rollup |
| **Routing** | Operation sequences — setup, run, move, queue time |
| **Work Center** | Machine/line — capacity, efficiency, utilization, status |
| **Materials** | Required vs available, reservations, shortages |
| **Operations** | Shop floor — start, pause, resume, finish, reject, scrap |
| **Quality Control** | Incoming / In-process / Final QC — inspection, defect, CAPA |
| **Output** | Finished goods, rejected, scrap tracking |
| **Costing** | Standard vs actual — material, labor, machine, overhead |
| **Maintenance** | Machine maintenance schedule |
| **Timeline** | Full production timeline |
| **Activity Log** | Complete audit trail |
| **Documents** | BOM docs, QC certificates |
| **History** | Complete production history |

## Production Types

| Type | Description |
|------|-------------|
| Assembly | Standard assembly |
| Disassembly | Tear down |
| Rework | Fix defects |
| Refurbishment | Restore to like-new |
| Repair Build | Repair + rebuild |
| Custom Assembly | Custom specification |
| Batch Production | Batch manufacturing |
| Make To Stock | Produce for inventory |
| Make To Order | Produce for specific order |

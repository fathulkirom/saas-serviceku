# Employee Workspace

> Complete employee lifecycle workspace — 14 tabs, 4 sidebar widgets.

---

## Tab List

| Tab | Key | Content |
|-----|-----|---------|
| **Overview** | overview | HR KPI — employee count, attendance rate, leave status, birthdays, dept distribution |
| **Profile** | profile | Full employee data (personal, employment, bank, tax, emergency) |
| **Attendance** | attendance | Clock in/out records, GPS location, photo, status |
| **Schedule** | schedule | Shift calendar (morning/afternoon/night/flexible/split/rotating) |
| **Leave** | leave | Leave balance, request form, approval workflow, history |
| **Payroll** | payroll | Salary slips, payroll history, tax breakdown |
| **Performance** | performance | KPI, targets, evaluations, grades (A-E), recommendations |
| **Training** | training | Programs, schedule, instructor, attendance, certificates |
| **Recruitment** | recruitment | Pipeline (screening→interview→test→offer→hired), applicant tracking |
| **Assets** | assets | Assigned assets (laptop, phone, tools, uniform, access card, vehicle) |
| **Documents** | documents | Contracts, certificates, KTP, NPWP, BPJS |
| **Timeline** | timeline | Full HR timeline (hire, promotion, training, leave, review) |
| **Activity Log** | activity | Audit trail of all HR actions |
| **Notes** | notes | Internal HR notes |

# Portal Security

> OTP, device session, login history, rate limit, permission check, audit.

---

## 🔒 Security Layers

| Layer | Description |
|-------|-------------|
| OTP Ready | One-time password login |
| Device Session | Track active device sessions |
| Login History | View login attempts |
| Activity Log | All portal actions logged |
| Rate Limit | Prevent brute force |
| Permission Check | Respect `can()` for all actions |
| Audit Trail | Complete audit log per portal |
| Data Isolation | Customer sees only own data |
| Technician Isolation | Technician sees only assigned jobs |

# Production Costing

> Standard vs actual cost tracking with Finance integration.

---

## 💰 Cost Components

| Component | Description |
|-----------|-------------|
| Material Cost | BOM component costs |
| Labor Cost | Operator hours × rate |
| Machine Cost | Machine hours × rate |
| Overhead | Indirect costs |
| Subcontract | External processing |
| Scrap Cost | Cost of rejected/scrapped |

---

## 📊 Variance Analysis

```
Standard Cost (Planned)
  - Actual Cost (Real)
  = Variance
  → Favorable (actual < standard)
  → Unfavorable (actual > standard)
```

---

## 🔗 Finance Integration

- Production Completion → Auto Journal
- COGM (Cost of Goods Manufactured) → Inventory Valuation
- Variance → P&L adjustment

# Webhook Engine

> Incoming/outgoing webhooks with HMAC signature validation, retry queue, DLQ.

---

## 🪝 Webhook Features

| Feature | Description |
|---------|-------------|
| Incoming Webhooks | Receive from external systems |
| Outgoing Webhooks | Send to external systems |
| Retry Queue | Auto-retry with exponential backoff |
| Signature Validation | HMAC-SHA256 verification |
| Secret Verification | Shared secret validation |
| Replay Protection | Prevent duplicate delivery |
| Delivery Status | Track every delivery attempt |
| Retry History | Full retry log |
| Dead Letter Queue | Failed after max retries |

# Asset Workspace

> Complete asset lifecycle workspace — 14 tabs, 4 sidebar widgets.

---

## Tab List

| Tab | Key | Content |
|-----|-----|---------|
| **Overview** | overview | KPI — assets, value, maintenance due/overdue, depreciation, categories, expiring, movements |
| **Profile** | profile | Full asset data (general, financial, maintenance config, location) |
| **Maintenance** | maintenance | Scheduled + in-progress maintenance, checklist, technician assignment, cost tracking |
| **Maintenance History** | maintenance_history | Complete log of all maintenance activities |
| **Depreciation** | depreciation | Monthly schedule, accumulated depreciation, book value, method |
| **Movement** | movement | Transfer, assignment, return, disposal, sale, write-off history |
| **Assignment** | assignment | Current custodian, department, branch, project |
| **Warranty** | warranty | Warranty period, vendor, claims, expiry tracking |
| **Insurance** | insurance | Policy, coverage, premium, renewal dates, claims |
| **Calibration** | calibration | Tool/equipment calibration due dates + history |
| **Inspection** | inspection | Inspection records + findings |
| **Documents** | documents | Manuals, invoices, purchase docs, photos |
| **Timeline** | timeline | Full asset lifecycle timeline |
| **Activity Log** | activity | Audit trail |

---

## Features

- [x] 15 asset categories (building, office, workshop, machine, equipment, computer, laptop, printer, vehicle, furniture, tool, network, server, POS, other)
- [x] Barcode + QR code ready
- [x] 4 depreciation methods (straight-line, declining balance, double declining, units of production)
- [x] 8 maintenance types (preventive, corrective, emergency, inspection, calibration, cleaning, repair, replacement)
- [x] 9 movement types (purchase, transfer, assignment, return, maintenance, repair, disposal, sale, write-off)
- [x] Warranty + extended warranty tracking
- [x] Insurance policy + premium tracking
- [x] Vehicle management (license plate, odometer, fuel, tax, service)
- [x] Tool calibration + borrow/return

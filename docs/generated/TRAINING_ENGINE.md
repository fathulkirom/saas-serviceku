# Training Engine

> Employee training management: programs, schedules, attendance, exams, certificates.

---

## 🎓 Training Lifecycle

```
Training Planned
  → Schedule + Instructor assigned
  → Participants registered
  → Training In Progress
  → Attendance tracked
  → Exam/Evaluation
  → Certificate issued
  → Completed
```

---

## 📚 Training Categories

| Category | Description |
|----------|-------------|
| Technical | Technical skills (repair, tools, software) |
| Soft Skills | Communication, leadership, service |
| Compliance | Safety, regulation, SOP |
| Product | Product knowledge |
| Onboarding | New employee orientation |

---

## 📊 Training Metrics

| Metric | Description |
|--------|-------------|
| Programs | Total training programs |
| Participants | Total employees trained |
| Completion Rate | % completed vs registered |
| Avg Score | Average exam score |
| Satisfaction | Participant feedback score |

---

## 🔗 Integration

| Integration | Description |
|-------------|-------------|
| Performance | Low score → training recommendation |
| Employee Profile | Certificates in profile |
| Automation | Training reminder notification |

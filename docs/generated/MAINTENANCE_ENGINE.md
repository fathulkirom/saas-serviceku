# Maintenance Engine

> CMMS — full preventive, corrective, emergency maintenance with scheduling, checklist, cost tracking.

---

## 🔧 Maintenance Types

| Type | Description | Trigger |
|------|-------------|---------|
| Preventive | Scheduled routine maintenance | Calendar/Meter |
| Corrective | Fix after failure | Breakdown event |
| Emergency | Urgent repair | Critical failure |
| Inspection | Periodic check | Schedule |
| Calibration | Tool/equipment precision check | Schedule |
| Cleaning | Routine cleaning | Schedule |
| Repair | Fix specific issue | Work order |
| Replacement | Replace part/component | End of life |

---

## 📅 Maintenance Calendar

| Frequency | Example |
|-----------|---------|
| Daily | Clean POS device |
| Weekly | Check printer toner |
| Monthly | Lubricate machine |
| Quarterly | Calibrate tools |
| Yearly | Full equipment inspection |
| Recurring | Every X days/usage |

---

## ✅ Maintenance Checklist

Each maintenance can have a checklist:
- [ ] Inspect condition
- [ ] Clean components
- [ ] Replace consumables
- [ ] Test functionality
- [ ] Document findings
- [ ] Update maintenance log

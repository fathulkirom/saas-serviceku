# CAPA Engine

> Corrective & Preventive Action management with effectiveness verification and automated tracking.

---

## 🔧 CAPA Types

| Type | Description |
|------|-------------|
| Corrective Action | Fix existing non-conformance |
| Preventive Action | Prevent potential non-conformance |

---

## 📋 CAPA Lifecycle

```
Identify → Create CAPA → Assign PIC → Implement → Verify Effectiveness → Close
```

### Key Features
- Auto-generation from audit findings and incidents
- PIC assignment with due date tracking
- Overdue alerts via Automation Engine
- Effectiveness verification (Implemented ≠ Effective)
- Trend analysis of CAPA effectiveness
- Root cause analysis integration

---

## ⏱️ SLA Tracking

- Due date countdown with color indicators
- Overdue escalation to manager/director
- Effectiveness rating (1–5 scale)
- Closure rate metrics for governance scorecard

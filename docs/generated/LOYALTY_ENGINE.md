# Loyalty Engine

> Points, rewards, membership tiers, referral, cashback, wallet.

---

## ⭐ Loyalty Features

| Feature | Description |
|---------|-------------|
| Points Earn | Per transaction (Rp X = 1 point) |
| Points Redeem | Discount with points |
| Points Expiry | Auto-expire after N months |
| Membership Tiers | Regular → Silver → Gold → Platinum |
| Birthday Reward | Bonus points on birthday |
| Referral Bonus | Points for referring new customers |
| Cashback | % cashback to wallet |
| Customer Wallet | Store credit balance |
| Coupon Rewards | Redeem points for coupons |

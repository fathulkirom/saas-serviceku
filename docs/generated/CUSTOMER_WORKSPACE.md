# Customer Workspace

> Full customer lifecycle workspace — 13 tabs, 6 sidebar widgets, 4 inspector sections.

---

## Tab List (13)

| Tab | Key | Content |
|-----|-----|---------|
| **Overview** | overview | Customer 360° — metrics, member card, favorites |
| **Profil** | profile | Full customer detail form |
| **Timeline** | timeline | Combined timeline view |
| **Riwayat Servis** | service_history | All services |
| **Riwayat Pembelian** | purchase_history | All purchases |
| **Invoice** | invoices | All invoices |
| **Pembayaran** | payments | Payment history |
| **Device** | devices | Device management (IMEI, serial, warranty check) |
| **Garansi** | warranty | Active warranties |
| **Komunikasi** | communication | WA, SMS, email history |
| **Catatan** | notes | Internal notes, pinned, mentions |
| **Dokumen** | documents | Attachments |
| **Aktivitas** | activity | Activity log |

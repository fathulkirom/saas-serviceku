# GRC Deprecation

---

## ❌ Deprecated in Sprint 34

| Component | Replacement |
|-----------|-------------|
| Spreadsheet risk registers | Risk Register (Data Engine) |
| Manual compliance checklists | Compliance Matrix |
| Email-based incident reporting | Incident Management |
| Paper audit checklists | Audit Engine |
| Ad-hoc CAPA tracking | CAPA Engine |
| Manual control testing logs | Internal Control Engine |
| Excel governance scorecards | Governance Dashboard |
| Manual fraud reviews | AI Fraud Detection |
| Siloed compliance tracking per module | Unified Compliance Matrix |
| Paper-based evidence folders | Digital Evidence Management |
| Email approval for risk decisions | Workflow-integrated approval |
| Standalone risk assessment tools | Integrated Risk Assessment |

---

## 🔄 Migration Path

All legacy GRC data should be migrated to the GRC Center:
1. Export existing risk registers → Import to Risk Register
2. Map compliance requirements → Compliance Matrix
3. Migrate incident logs → Incident Management
4. Link existing findings → Audit Findings
5. Convert CAPA spreadsheets → CAPA Engine
6. Map controls → Internal Control Engine

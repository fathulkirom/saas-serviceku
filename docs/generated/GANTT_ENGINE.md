# Gantt Engine

> Project timeline with dependencies, critical path, milestones, and baseline comparison.

---

## 📅 Features

| Feature | Description |
|---------|-------------|
| Timeline | Bar chart by date |
| Dependencies | Finish-to-Start, Start-to-Start, etc. |
| Critical Path | Auto-highlight longest path |
| Progress | % complete overlay on bars |
| Milestones | Diamond markers on timeline |
| Baseline | Original plan comparison |
| Delay Indicator | Red highlight for overdue |
| Zoom | Day / Week / Month / Quarter / Year |
